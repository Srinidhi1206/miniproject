Figure 3

Detection models & risk scoring

Two supervised models estimate likelihood; named rules explain tactics; a documented formula combines both.

Text scam classifier

Data

UCI SMS Spam (5,160) + curated India-specific set (242, ×3 weight)

→

Normalise

placeholders: urltoken moneytoken phonetoken

→

Model

word 1–2 + char 3–5 TF-IDF → Logistic Regression

Hold-out: F1 0.950 · ROC-AUC 0.991 · curated subset F1 0.909  |  + 22 tactic rules (OTP/PIN request, upfront fee, digital arrest…)

URL risk analyzer

Data

PhiUSIIL 235k URLs + Tranco top-30k popular domains

→

Features

registered domain only: char 2–5 grams + 11 lexical features

→

Model + rules

Logistic Regression + 20+ rules (brand look-alike, typosquat, IP, shortener, .apk…)

Domain hold-out ROC-AUC 0.81 · system: 0.6% false HIGH on unseen popular sites · 84% of phishing URLs warned/flagged

↓
Risk engine (deterministic)

component score = model points + clamp(Σ rule weights) · documented floors (e.g. 2 critical tactics → ≥ 80)
final = max(components) + 5 × (other components ≥ 50), capped at +10
